# Blue Skin Studio

A free, browser-only Minecraft skin utility.

## Features
- Load a 64x64 PNG skin texture (also accepts 64x32 legacy textures).
- Preview the uploaded texture.
- Download the original PNG.
- Create an .mcpack skin-pack archive with a manifest and skin metadata.

## Run locally
Open index.html in a modern browser. No build step, database, API key, or account is needed.

Skin files are processed locally in your browser and are not uploaded to a server.

Minecraft Education custom skin-pack import behavior can vary by version and device; successful import is not guaranteed on every installation.
